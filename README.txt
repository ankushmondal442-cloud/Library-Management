LIBRARY MANAGEMENT SYSTEM — UPDATED DBMS PROJECT
Group: G2 | Database: MySQL 8.0+

PACKAGE CONTENTS
- Library_Management_System_Professional_Report_200_Queries.docx: updated professional report documenting the 200-query bank.
- library_management_system_200_queries.sql: complete schema, constraints, sample data and 200 numbered SQL queries.
- Professional_ER_Diagram.png: ER diagram matching the database schema.
- README.txt: setup and execution guide.

RUN IN MYSQL WORKBENCH
1. Install MySQL Server 8.0+ and MySQL Workbench.
2. Open library_management_system_200_queries.sql and connect to your local server.
3. Execute the script from the beginning. IMPORTANT: it drops and recreates a database with this name.
4. Refresh SCHEMAS and expand library_management_system.
5. Run the numbered queries Q001–Q200 individually from the bottom query bank.

QUERY COVERAGE
Q001–Q020: Catalogue and book search
Q021–Q040: Authors, publishers and categories
Q041–Q065: Members
Q066–Q090: Physical inventory and availability
Q091–Q120: Loans and circulation
Q121–Q140: Reservations
Q141–Q160: Fines
Q161–Q180: Dashboards and operational reports
Q181–Q200: Advanced SQL (CTEs, window functions, UNION and CASE)
